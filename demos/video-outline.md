## Recording notes

- **Do not** show real credentials at any step; the WSS dummies (esb-client / erp-wss-pass-2026) are documented sim dummies and may appear only inside config files already in the repo.
- Sections 4–6 need the stack from section 2 running: `make up` + `make smoke` exit 0 before recording; `./scripts/esb-toxiproxy.sh ensure` before section 5; `make esb-stop` after section 6.
- Scene 5's fail-pricing beat needs the ESB booted with `ESB_FAULT_INJECTION=true` (`make esb-run` hardcodes false — boot the ESB jar manually with the flag, or reuse the suite's own harness), then POST with header `X-Fault-Injection: fail-pricing`; the automated equivalent is `make esb-int` (tests/esb-int). The DLQ event view: `kafka-console-consumer.sh --topic silkroute.esb.dlq --from-beginning --timeout-ms 4000` inside sim-kafka.
- Section 7 runs offline by design: `make plan-sg` performs no AliCloud API calls. Say the "validated IaC, sim runtime" line on camera — it must be audible, not just visible.
- Keep each evidence-artifact flash to 2–4 seconds; the filename must be readable.
- If a live command misbehaves on camera, cut and re-record that section — never narrate over a failure with "usually works".
